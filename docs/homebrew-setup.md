# Homebrew Tap Setup Guide

This guide explains how to set up Homebrew distribution for gz-git.

## Prerequisites

1. GitHub organization/user: `gizzahub`
1. GoReleaser configuration: `.goreleaser.yaml` (already created)
1. GitHub Actions workflow: `.github/workflows/release.yml` (already configured)

## Step 1: Create Homebrew Tap Repository

Create a new GitHub repository named `homebrew-tap`:

```bash
# Repository name must start with "homebrew-"
# URL: https://github.com/gizzahub/homebrew-tap
```

### Repository Structure

```
homebrew-tap/
├── README.md
├── Casks/
│   └── gz-git.rb    # Auto-generated by GoReleaser
└── .github/
    └── workflows/
        └── tests.yml  # Optional: test formulas
```

### Sample README.md for homebrew-tap

````markdown
# Homebrew Tap for gizzahub

## Installation

```bash
brew tap gizzahub/tap
brew install --cask gz-git
```

## Available Casks

| Cask   | Description                        |
| ------ | ---------------------------------- |
| gz-git | Git repository management CLI tool |

## Updating

```bash
brew update
brew upgrade gz-git
```

````

## Step 2: Create Personal Access Token (PAT)

1. Go to GitHub Settings > Developer settings > Personal access tokens > Tokens (classic)
1. Click "Generate new token (classic)"
1. Configure:
   - **Note**: `homebrew-tap-token`
   - **Expiration**: Set appropriate expiration
   - **Scopes**: Select `repo` (full control of private repositories)
1. Copy the generated token

## Step 3: Add Repository Secret

1. Go to `gzh-cli-gitforge` repository settings
1. Navigate to Secrets and variables > Actions
1. Click "New repository secret"
1. Configure:
   - **Name**: `HOMEBREW_TAP_TOKEN`
   - **Value**: Paste the PAT from Step 2

## Step 4: Release

When you push a new tag, GoReleaser will:

1. Build binaries for all platforms
1. Create GitHub release with assets
1. Auto-update the Homebrew cask in `homebrew-tap`

```bash
# Create and push a new tag
git tag v1.0.0
git push origin v1.0.0
```

## User Installation

After release, users can install via:

```bash
# Add tap and install
brew tap gizzahub/tap
brew install --cask gz-git

# Or in one command
brew install --cask gizzahub/tap/gz-git

# Verify installation
gz-git --version
```

## Bootstrap the Empty Tap

As of 2026-08-25, `gizzahub/homebrew-tap` has no refs or published Formula, so
there is no existing Formula-to-Cask migration to perform. Before the first
stable release, verify the external publishing path end to end:

1. Initialize the tap with a default branch and README.
1. Confirm `HOMEBREW_TAP_TOKEN` can publish `Casks/gz-git.rb`.
1. Audit the generated Cask and install it on macOS from the tap.
1. Confirm `gz-git --version` reports the stable tag.

This bootstrap is a release operation in the external tap, not a migration
performed by this repository.

## Updating a Cask Manually (Optional)

If you need to update the cask manually:

```bash
# Clone tap repository
git clone https://github.com/gizzahub/homebrew-tap.git
cd homebrew-tap

# Edit cask
vim Casks/gz-git.rb

# Test locally
brew install --cask ./Casks/gz-git.rb

# Commit and push
git add Casks/gz-git.rb
git commit -m "Update gz-git to vX.Y.Z"
git push
```

## Troubleshooting

### Token Permission Issues

If GoReleaser fails to push to homebrew-tap:

- Verify PAT has `repo` scope
- Ensure PAT is not expired
- Check `HOMEBREW_TAP_TOKEN` secret is correctly set

### Cask Validation

Test cask syntax locally:

```bash
brew audit --cask Casks/gz-git.rb
brew style Casks/gz-git.rb
```

### Installation Issues

```bash
# Force reinstall
brew reinstall --cask gz-git

# Check for conflicts
brew doctor

# View installation logs
brew install --cask gz-git --verbose --debug
```
