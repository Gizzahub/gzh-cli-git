## Background

`tasks/README.md`는 **20316 바이트 / 286줄**이다. doc-standards 가이드라인은 500줄 / 10KB이므로
**용량 기준을 2배 초과**했다(줄 수는 여유 있음 — 한 줄이 긴 표가 많다는 뜻).

이 파일은 인덱스로 출발했는데 지금은 완료 기록과 감사 이력이 본문의 대부분을 차지한다.
2026-08-05 시점에 11098바이트로 한 번 초과했고, 그때는 내가 추가한 분량만 줄여
10347바이트로 맞췄다. 이틀 만에 두 배가 됐다 — **줄이는 방식으로는 유지되지 않는다.**

## 무엇이 자라고 있나

`grep -n "^#\{1,3\} " tasks/README.md` 기준 섹션 분포:

| 섹션 | 시작 줄 | 성격 |
|---|---|---|
| 구조 / Open Issues | 5, 75 | **인덱스** — 여기 남아야 함 |
| 완료 (2026-08-05) + 하위 3개 | 20~74 | 완료 기록 |
| 날짜별 작업 로그 6개 | 86, 106, 115, 177, 188, 209 | 완료 기록 (가장 빠르게 증가) |
| 감사 이력 | 228~ | 감사 결과 |
| v0.7.0 사용자 우회법 | 267~ | 릴리스 노트 성격 |

증가분은 전부 **"끝난 일의 기록"** 이고, 인덱스로서 매번 읽을 필요가 있는 부분은
`구조`와 `Open Issues` 두 곳뿐이다.
